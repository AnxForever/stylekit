# StyleKit Product Context

StyleKit is an AI-friendly UI design system and prompt library for designers and builders who need concrete visual direction, reusable design tokens, component recipes, templates, and implementation-ready motion patterns.

The product should favor practical browsing, copying, comparing, and exporting workflows over marketing-heavy presentation. Expressive effects are appropriate inside dedicated showcase and demo pages; catalog covers, template cards, admin screens, forms, and dense browsing surfaces should stay stable, readable, and fast.

Pointer and mouse interactions are opt-in enhancements. They must respect `prefers-reduced-motion`, run only on suitable pointer devices, avoid React state updates inside high-frequency pointer events, and never obscure native controls, text selection, keyboard focus, or assistive technology semantics.
