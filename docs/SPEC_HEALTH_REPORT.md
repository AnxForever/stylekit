# StyleKit Spec Data Health Report

Generated by `scripts/verify-spec.py`. **146 styles checked, 124 with at least one internal contradiction, 584 total issues.**

## Issue type summary

| Type | Count | Meaning |
|------|-------|---------|
| `forbidden_in_template` | 38 | A class the style forbids appears inside a shipped component template — agents copy templates, so this guarantees a violation |
| `required_unbacked` | 373 | A required class the style demands for a component has no example in that component's template |
| `token_color_out_of_palette` | 173 | Token colors reference a hex not present in the style's palette |
| `missing_field` | 0 | Required spec field (doList/dontList/aiRules/components/tokens) is empty |

## Fix guidance

For each style, resolve contradictions in this order:

1. **`forbidden_in_template`** — edit the component template to remove the forbidden class (highest impact: template is copied by agents).
2. **`required_unbacked`** — either add the required class to the template, or remove it from the required table (template wins).
3. **`token_color_out_of_palette`** — add the hex to the style palette, or change the token to a palette color.

After fixing a style, re-run: `python3 scripts/verify-spec.py <slug>`
