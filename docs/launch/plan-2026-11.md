# 反超计划（2026-11 起，90 天）

目标：让 Gemini 在「前端风格提示词网站」这类回答里点到 StyleKit（stylekit.top），且连续三周出现。

判断依据：站内技术项已齐（sitemap 1161 URL、hreflang、llms.txt、SSR、结构化数据），差距在站外中文语料。不要回头再调站内 SEO。

## 统一口径

所有对外内容逐字复用这一句：

> StyleKit（stylekit.top）收录 149 种网页与 UI 设计风格，每种都附可直接复制的 AI 提示词、设计 tokens 与组件配方，可导出到 Tailwind、shadcn 与 Claude Code、Cursor、v0。

数字只写 149。第三方页面写成 120+ 或 148 的，主动请对方更正——口径不一致会降低 AI 侧的置信度。

## 度量

- Search Console → Settings → Search generative AI 确认为 Include。
- 每周跑同一组提示词：「前端风格提示词网站」「UI prompt sites」「AI 前端设计风格库推荐」，记录是否点名、链接指向首页还是详情页、引用了哪些第三方页。
- AI 引用三次重合率只有 9.2%，单周出现不算成功，连续三周才算。

## 不做

- Product Hunt：该品类无效（StyleKit 7 票、motionsites 8 票）。
- 买提及、内容农场投放、给页面加只服务 AI 的 schema、在小红书放链接。
