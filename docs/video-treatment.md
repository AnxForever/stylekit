# StyleKit 宣传片 — 导演阐述与分镜台本

片名：《不再漂移》
英文副题：StyleKit — 148 Curated Visual Styles for AI-Built Pages

- 规格：1920×1080 · 60fps · 52 秒 · 26 小节 · 无对白
- 乐理骨架：120 BPM。1 拍 = 0.5 s = 30 帧。1 小节（4 拍）= 120 帧 = 2 s
- 源码：`tools/promo-video/`　成片：`tools/promo-video/out/stylekit-promo.mp4`

## 一、核心创意

README 里最锋利的一句是：「问题不在模型 —— 而是「做得好看点」本来就不算一句规格。」

整支片子就围绕这句话做戏剧。**前 20 秒先让观众看够了"AI 味"**：紫蓝渐变、
居中圆角卡片、同一句英文标题反复堆叠、抖动、色差，让画面痒得让人不舒服；
然后**一刀切黑**，承认这就是问题；再给出答案 —— StyleKit 把抽象品味翻译成
机器能执行的规格。

视觉母题用**四宫格（2×2 方块）**：它既是 README 里初代 LOGO 的像素结构，
也是品牌 v2 的 SK 徽标的解构。全片用四种方式重复它：四种风格同框 →
148 宫格信息场 → 全屏方块阵列 → 片尾徽标。这是"重复母题"的经典手法。

## 二、情绪曲线

```
蓄势  0.0– 4.0s   黑暗中四格方块依次亮起，镜头几乎静止
焦虑  4.0–18.0s   高密度碎片、快切、抖动 —— 观众开始不适
骤停 18.0–20.0s   三连重音 + 静帧 + 双步渐黑（dying fall）
转折 20.0–24.0s   黑场，两句话把问题讲清楚
释放 24.0–28.0s   白闪 + 爆炸，148 个真实色块炸开
展开 28.0–38.0s   钟摆节奏：先一个问题，再一份规格
接入 32.0–38.0s   三条命令，逐字打出
高潮 38.0–46.0s   148 宫格信息场 + 俯冲减速，数字落定
沉淀 46.0–52.0s   亮底收束、徽标、域名
```

## 三、运镜语言（全片只用四种镜头）

| 镜头 | 用法 | 数值 |
|---|---|---|
| 缓推 push | 让画面"驶入"观众，每段落点 | 1.0→1.12，3–5 s，ease-out |
| 俯冲 crane | 从满屏方格阵列中抬起再落定 | scale 1.5→0.7 + rotateX 30°→4° |
| 冲击 punch | 只有揭示一次 | 2.35→1.0，0.35 s |
| 静止 hold | 必须读字的段落一律不动 | — |

剪辑原则：**同一种转场全片不超过两次**。本片转场只用：硬切、白闪、黑场。

## 六、声音设计

全部程序化合成，48kHz 立体声，无版权顾虑：

- 底鼓 / 军鼓 / 踩镲：噪声 + 正弦包络，`dsp.mjs` 里手写
- Sub bass：正弦 + 饱和，跟kick走
- Pluck / 琶音：三角波谐波 + 快速衰减；本片的动机 D–A–F–E
- Pad：三振荡器 ±9 音分失谐 + 一阶低通
- Riser：噪声带通扫频；Whoosh：钟形包络噪声，给转场
- Impact：低频正弦下滑 + 噪声爆裂，只给揭示和数字落定
- 混响：4 comb + 2 allpass（Schroeder 近似），手写

调性：问题段 D 自然小调（f 小调大七 #11 制造"舒服但不对"），
揭示后转 D 大调 —— 同一动机变奏，听感直接由灰转亮。

母带：soft-clip 后峰值归一化到 −1 dBFS，实测平均 −16.2 dB。

## 七、技术方案

Remotion 4（React → 视频），1080p / 60fps，H.264 crf 18 + preset slow。
所有动效由 `useCurrentFrame()` 驱动，不用任何 CSS 动画（保证逐帧确定性）。
中文标题走 `fit-text.ts` 估算字宽，保证永不溢出安全区。
