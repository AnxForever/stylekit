## 2. 逐字证据编码

建议为引用附上一个或多个标签：

- `workflow`：当前真实流程
- `pain`：明确问题
- `frequency`：发生频率
- `cost_time` / `cost_money`：时间或金额代价
- `consequence`：延期、质量、流失等后果
- `alternative`：替代方案
- `paid_before`：真实历史支出
- `price_accept` / `price_reject`：主价格接受或拒绝
- `missing_deliverable`：阻止购买的缺失项
- `license_objection` / `trust_objection` / `timing_objection`
- `deposit_action` / `payment_action`：已发生的高成本行动
- `counterevidence`：反证

编码用于发现重复模式，不能把同一人的多条引用当成多个独立受访者。
