## 浏览器验收

使用独立浏览器会话验证本地开发服务与生产构建预览：

- 购物规格面板打开后焦点进入面板；选择 360 ml 后按 Escape 关闭，焦点返回触发按钮，选择保留；加入购物袋后数量更新。
- 任务完成后进度从 1/3 更新为 2/3；收藏文章后能在书架找到它。
- SwiftUI 筛选显示 ChunUI、ShipSwift，不混入 Vant；无匹配结果时提供重置操作。
- 360、390、430、1440 px 下均无横向溢出；人工检查桌面、手机和深色组件列表截图。
- 中英文标题、页面语言、canonical 路径与组件数量正确。三个路由的生产构建 HTTP 响应均为 200。
- 全站搜索输入 `ChunUI` 能找到移动端入口；资源页显示本地化链接；复制开发要求显示成功反馈。
- axe 4.12.1 对新页面内容区域的浅色、深色扫描均为 0 条 violations，各有 1 条需人工复核的色彩对比项目；这不是整站或原生设备的无障碍认证。
