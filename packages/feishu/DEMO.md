# Demo 视频脚本（≤3 分钟，实机演示）

## 拍摄纪律

- 全程实机，不剪假，不用 PPT 架构图
- 飞书界面出镜总时长 ≥ 50% —— 「飞书在运行时」要视觉上不证自明
- 先果后因：开场先亮成品，别从架构讲起
- 高潮留给合规体检（这是与对手拉开差距的一段）
- 手机端竖屏竖拍，或桌面端横屏，全程稳定，配字幕或旁白

## 分段

### 0:00–0:20 痛点 + 成品暴击

- 一句话痛点：「设计风格这事，说不清、传不准、写不对。」
- 一屏扫过最终交付物：Cursor Rules / shadcn 主题 / Tailwind preset / Figma tokens 四件套 + 一个渲染出来的漂亮页面
- 旁白点题：「让 AI 写出来的前端，风格不再随机。」

### 0:20–1:40 完整跑一遍核心流程

1. 真机在飞书群里 @机器人：「做一个面向 Z 世代的潮牌电商落地页，要炸裂但别太吵」
2. **镜头停在飞书界面上**：流式卡片把推理过程打字机式打出来，最后落定「推荐：赛博朋克霓虹」+ 两个备选按钮
3. 点「就用这个」
4. 镜头切多维表格：新记录自动写入（风格 / 主色 / 提示词字符数 / 规范文档链接）—— **这一帧是「飞书参与运行」的视觉铁证，务必拍到**
5. 打开《设计规范交付单》文档，翻两页展示内容（项目画像 / 风格要诀 / 工程包清单）

### 1:40–2:30 高潮：合规体检闭环

1. 打开 Cursor 或 Claude Code，把 AI 写好的一个 button 组件复制下来
2. 贴回飞书群
3. 机器人秒回体检卡片：「3 处错误」—— `rounded-xl`（该风格禁圆角）、`bg-gradient-to-r`（禁渐变）、`shadow-lg`（禁软阴影），**每条带修复建议**
4. 按建议改完再贴一次
5. 卡片变绿：「风格合规，5 个类名全部通过」—— 顺手给一个镜头：多维表格里「体检结果」字段已经被自动回写

### 2:30–3:00 复用邀请

- 展示上手指南三步：`pnpm install` → `pnpm --filter stylekit-feishu register`（扫码）→ `dev`
- 收尾一句：「换个 slug，就是你的项目。代码和指南都在 GitHub。」
