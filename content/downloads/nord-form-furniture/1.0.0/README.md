## Technical notes / 技术说明

Created with Blender 4.3.2. Meter units; GLB uses Y-up and a floor-centered origin. The ten models have 7,172 evaluated triangles in total. Static models only: no rig, animation or collision mesh. Materials use colors without external image textures. The Blender file includes a presentation studio; individual GLB exports contain isolated furniture. Consult inventory.json for per-model dimensions, materials and triangle counts.

由 Blender 4.3.2 制作，单位米；GLB 使用 Y 轴向上、底部中心原点。十个模型评估后三角面合计 7,172。仅含静态模型，无绑定、动画或碰撞体；材质使用颜色，无外部图像纹理。Blender 源文件含展示摄影棚，独立 GLB 仅含对应家具。逐模型尺寸、材质和面数见 inventory.json。
