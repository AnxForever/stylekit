## Contents / 内容

A compact low-poly delivery spacecraft with ivory pressure hull, orange outriggers and a secured freight module.

象牙白船体、橙色侧舱与固定货箱组成的低多边形太空快递飞船。

This package contains the actual GLB model and editable Blender source. Web previews are compressed copies of renders supplied with the model. See the supplied source notes and geometry metadata for model-specific details.
